A small inline status label: an 8px colored dot and a word on a `color-surface` pill.

**You provide:** a word or short phrase. The word carries the meaning; the dot only reinforces it.

Hug × 32, padding `space-4` / `space-12`, gap `space-8`, `radius-full`, `body-sm` 700. Dot colors: `Eyebrow` `color-primary`, `Success` `color-success`, `Warning` `color-warning`, `Error` `color-error`.

**Do**
- Use badges inline, inside cards, lists and metadata.
- Always pair the dot with text.

**Don't**
- Open a section with `Badge/Eyebrow`; use the `SectionEyebrow`.
- Fill the badge with the state color, or use `color-warning` as text on a light background.
